strcpy vs strncpy?	<code>strcpy</code> copies up to and including the NUL; <code>strncpy</code> exactly n bytes – pads with 0, or leaves the result unterminated.	OS AG::7 POSIX	ag::posix
pthread_cond_wait(cond, mutex)?	atomically: release mutex + wait; on return it holds the mutex again. Call it in a while loop.	OS AG::7 POSIX	ag::posix
sem_wait / sem_post?	<code>sem_wait</code>: wait until value &gt; 0, then decrement; <code>sem_post</code>: increment (wakes a waiter).	OS AG::7 POSIX	ag::posix
mmap(NULL, len, PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANONYMOUS, -1, 0)?	len bytes of new, zeroed memory; failure: MAP_FAILED = (void*) −1.	OS AG::7 POSIX	ag::posix
Page vs frame?	page = virtual (vpn), frame = physical (ppn); both 4096 bytes. The page table maps vpn → ppn.	OS AG::8 Basics	ag::basics
x86-64 page-table tree?	PML4 → PDPT → PD → PT, 512 entries each, 9 bits of the address per level; the lower half of the PML4 = user space.	OS AG::8 Basics	ag::basics
TLB?	the CPU's cache of translations – stale after a change that removes rights → flush.	OS AG::8 Basics	ag::basics
Lazy loading?	a page of the program is loaded only on its first access (page fault → <code>loadPage</code>).	OS AG::8 Basics	ag::basics
ELF: sections vs segments?	sections (.text .rodata .data .bss) are the linker's view; LOAD segments are what the loader maps. .bss = MemSiz &gt; FileSiz (zeroed).	OS AG::8 Basics	ag::basics
Red zone?	128 bytes below rsp that a function may use without moving rsp – skip it before pushing something onto a user stack from the kernel.	OS AG::8 Basics	ag::basics ag::registers
Why must the kernel check user pointers?	a user program can pass any address – also a kernel address or one that crosses USER_BREAK; the kernel would read/write it with full rights.	OS AG::8 Basics	ag::basics
Timer frequency in SWEB?	18.2 Hz – a time slice is about 55 ms.	OS AG::8 Basics	ag::basics
