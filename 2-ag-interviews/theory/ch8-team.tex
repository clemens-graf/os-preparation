\section*{Found in your team's code}

\begin{itemize}
\item A thread sleeping in \code{pthread\_join} panics the kernel when another thread ends the
  process (\code{exitProcess} kills it, it stays in the waiters list of \code{thread\_exited\_}).
\item Fixed on 18 Oct (\code{pthread-cancel-points}): a thread sleeping in \code{pthread\_join} can
  be cancelled now --- \code{cancelThread} broadcasts, the wait loop checks the caller's flag.
\item \code{fork}: the child's \code{UserThread} copy does not get \code{user\_stack\_top\_} /
  \code{lowest\_mapped\_stack\_vpn\_} --- a forked child that needs a new stack page is killed
  with 666. Fix: copy both in the copy constructor.
\item \code{loadPage} maps without the page-table lock; \code{createThread} has no thread limit;
  \code{mkdir} starts with \code{-1U}.
\end{itemize}
